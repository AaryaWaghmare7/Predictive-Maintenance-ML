# Future RUL data

No verified RUL dataset is available in this checkout. On 2026-10-15 the user
confirmed that a collaborator previously downloaded data on Windows, but it
has not been supplied locally. Do not download, extract or train on new data.
Its run-to-failure records, endpoints and labels remain unverified here.
Raw/derived files in this directory are Git-ignored; this README is the only allowed exception.
Preserve original data separately from derived labels/features and retain
source/license information. Do not combine unrelated datasets by row index.

See `reports/11_RUL_Dataset_Requirements.md` before selecting any dataset.
The NEV fault CSVs are not degradation/run-to-failure data and must not be
used to invent RUL targets.
