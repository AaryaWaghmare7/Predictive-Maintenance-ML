CSV Telemetry Upload

Upload UTF-8 CSV with exactly the seven sensor columns below, in any order. No target, timestamp or vehicle-ID columns are accepted in this MVP.

Voltage (V),Current (A),Motor Speed (RPM),Temperature (°C),Vibration (g),Ambient Temp (°C),Humidity (%)

Maximum 5 MiB and 20,000 rows. Every row is validated; invalid uploads are rejected in full. Uploads are not retained by the application. Predictions are independent observations, not a temporal sequence.
