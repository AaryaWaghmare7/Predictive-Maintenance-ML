CSV schema & upload requirements

Seven sensor columns, in any order. Fault Label is not required.

  • Voltage (V)
  • Current (A)
  • Motor Speed (RPM)
  • Temperature (°C)
  • Vibration (g)
  • Ambient Temp (°C)
  • Humidity (%)

UTF-8 BOM and surrounding header spaces are supported. Extra columns are reported and ignored, never used for prediction.

Up to 5 MiB / 20,000 rows. All sensor cells must be finite numbers in [0,1]. Invalid uploads are rejected in full.

Prototype limitations

Normalized 0–1 inputs only; original physical-unit normalization parameters are unavailable. The NEV dataset has no timestamps or vehicle IDs: temporal and cross-vehicle generalization are not established. This is a research proof of concept, with performance measured on the Experiment 2 dataset. RUL is not implemented. No universal EV or manufacturer coverage is claimed.
